# GitHub repository setup

The suggested repository name is `cn-congestion-aware-traffic-rerouting`.
Create it under the team's GitHub account as a private repository. Do not
initialize it with a second README, license, or `.gitignore`; this folder
already has the starter documentation and ignore rules.

From this project folder, connect and push the local commit history:

```bash
git remote add origin https://github.com/vanshdev3/cn-congestion-aware-traffic-rerouting.git
git push -u origin main
```

Invite teammates using the usernames they provide. Keep the repository private
unless the team agrees otherwise. Work on short branches and open pull requests
for changes that affect shared code. The issue and pull-request templates are
already in `.github/`.

The GitHub remote has not been configured in this local folder. Add it only
after the repository exists in the team's account.
