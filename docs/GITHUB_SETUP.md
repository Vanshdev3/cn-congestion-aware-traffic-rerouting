# GitHub repository setup

The repository name is `cn-congestion-aware-traffic-rerouting`.
Create it under the team's GitHub account as a public repository. Do not
initialize it with a second README, license, or `.gitignore`; this folder
already has the documentation, license, and ignore rules.

From this project folder, connect and push the local commit history:

```bash
git remote add origin https://github.com/vanshdev3/cn-congestion-aware-traffic-rerouting.git
git push -u origin main
```

Invite teammates using their actual GitHub usernames. Work on short branches
and open pull requests for changes that affect shared code. The issue and
pull-request templates are already in `.github/`.

If GitHub is connected in the Codex app, the repository can be created and this
history can be pushed from there. Otherwise, create the empty public repository
in the GitHub website first, then run the commands above in this folder.
